This editor saves straight to your repository, and the push rebuilds and redeploys the site. It needs a GitHub token to do that.

  3. Permissions → Repository → Contents: Read and write, and Actions: Read-only (so this page can show build progress)
  4. Set an expiry you're comfortable with, generate, and paste it below
